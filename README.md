# YSN Advance Calculator

A browser-based calculator with a standard keypad and a set of supplementary math and utility tools.

![YSN Advance Calculator interface](https://yuvrajsinghnegi.vercel.app/images/projects/calculator.webp)

## Live demo

[Open YSN Advance Calculator](https://ichbinyuvii.github.io/Calculator/)

## Features

- Basic arithmetic, calculation history, and scientific functions including trigonometry, square root, logarithm, and pi.
- Additional tool views for matrices, graphs, programmer conversions, unit conversion, EMI, and BMI.
- Theme and interaction preferences.
- Responsive, single-file HTML interface.

## Run locally

Open `index.html` in a modern browser. No build step is required.
